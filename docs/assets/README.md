# Documentation image assets

`olo-db-viewer-snapshot.png` is the stable screenshot path used by the root README, quick-start guide, viewer README, and `llms.txt`.

The current file is a temporary shared OLO DB Viewer reference. It should be replaced with a screenshot from this repository showing Daily, Weekly, Monthly, and Quarterly TL/TL-OHLC overlays.

## Replacement procedure

1. Launch this repository's `olo-db-viewer.bat`.
2. Select a representative symbol and enable several stored TL overlays.
3. Capture the complete interface without credentials, private paths, or sensitive information.
4. Overwrite `olo-db-viewer-snapshot.png` with the new PNG.
5. Keep the filename unchanged so all existing links continue to work.
6. Preview the root README and `docs/QUICKSTART.md`.

The image is documentation only and is not an application runtime dependency.
